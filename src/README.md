# Frontend — SIH26017

React/Vite dashboard for the land-acquisition delay prediction system.

## Responsibilities
- Project selection and dashboard presentation
- Risk score and driver visualization
- What-If scenario controls
- GIS project visualization
- Recommendations and workflow views

## Run
```bash
npm install
npm run dev
```

Configure `VITE_API_URL` when the FastAPI server is not running on `http://localhost:8000`.

API-backed values should be preferred over mock/demo fallbacks. Demo-only authentication must remain clearly labeled as such.
