\# Setup Guide



\## 1. Project Requirements



Before running the Land Acquisition AI project, make sure the following software is installed:



\- Python 3.14 or compatible Python version

\- Git

\- GitHub account

\- Required Python packages

\- A code editor such as Visual Studio Code



The machine learning component uses Python and the following major libraries:



\- NumPy

\- SciPy

\- Pandas

\- Scikit-learn

\- Joblib

\- XGBoost
