# Team & Responsibilities

BhoomiIQ is organized as a cross-functional student project. The repository records responsibilities by workstream so a reviewer can see how the full-stack system is divided.

| Workstream | Primary responsibility |
|---|---|
| Product / SIH integration | Problem framing, feature prioritization, demo flow, and requirement alignment |
| Frontend | React/Vite dashboard, authentication UI, project views, What-If workflow, and user experience |
| Backend | FastAPI application, route contracts, model integration, project/recommendation services, and deployment interface |
| ML / Data Science | Dataset preparation, preprocessing, model training, evaluation, risk scoring, and SHAP explainability |
| GIS | Leaflet map, project coordinates, clustering, risk styling, and prototype parcel visualization |
| Testing / Documentation | Smoke tests, integration checks, deployment verification, user documentation, and judge-facing material |

## Collaboration model

The final submitted implementation is maintained on the `main` branch. Major technical changes should keep the README, API documentation, ML documentation, GIS documentation, and testing/deployment instructions consistent with the code.

## Contribution evidence

The Git history and repository structure provide the implementation record. For a competition submission, the official SIH/team registration materials should be treated as the authoritative source for individual member names and institutional details.
