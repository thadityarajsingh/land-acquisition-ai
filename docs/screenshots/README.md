# Judge Screenshot Checklist

Screenshots are intentionally not fabricated. Add real screenshots from the deployed or final local application here before the final SIH submission if screenshots are required.

## Recommended captures

1. `01-dashboard.png` — landing/dashboard overview.
2. `02-project-risk.png` — selected project with risk score/category.
3. `03-shap-explanation.png` — Risk Drivers / SHAP explanation.
4. `04-what-if.png` — baseline vs scenario comparison.
5. `05-gis.png` — GIS project map with risk styling.
6. `06-recommendations.png` — project recommendations/actions.
7. `07-api-docs.png` — deployed Swagger/OpenAPI page.

## Capture rules

- Use the final `main` build.
- Prefer the deployed frontend for the primary screenshots.
- Do not expose secrets, tokens, private user data, or internal credentials.
- If using synthetic demo records, keep the prototype/synthetic status clear in the surrounding documentation.
- Crop screenshots to the relevant application area and keep text readable.

These files are optional for running the project; they exist to reduce the time a judge needs to understand the finished UI.
